Layer 1 — address (URL) detection

True URL detection (look-alike domains, fake .gc.ca, punycode, etc.) depends on the real hostname, so it can’t be faked from localhost. It’s covered by the automated suite (node scripts/smoke-test.mjs), and you can see link-level detection inside the Layer 3 samples that contain suspicious links.
